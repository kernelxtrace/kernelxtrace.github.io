# Kernel x Trace

자동차 전장 분야에 몸담고 있는 개발자입니다.  
유저의 사용 통계를 수집하여 전송하는 미들웨어 서비스 개발을 시작으로,  
시스템에서 발생한 error, warning 등의 로그를 전달받아 리포팅하는 단말 관제 어플리케이션,  
각종 센서와 장치들로 부터 CAN 통신을 통해 전달되는 데이터를 프로토콜에 맞게 정제하여 MQTT 통신으로 차량-서버 간 동기화하는 서비스,  
AAOS 특화 소프트웨어로 eBPF를 사용해 커널 이벤트를 수집하여 이상 징후를 감지 후 서버로 전송하는 모니터링 서비스 등을 개발해왔습니다.

시스템의 밑바닥에서 발생하는 동작들을 추적하고 분석하는 과정에서 저수준 시스템 엔지니어링에 대한 깊은 흥미와 필요성을 느꼈습니다.  
시스템 프로그래밍, 리눅스 커널과 eBPF 트레이싱의 동작 원리 등을 본격적으로 학습하고 기록하기 위해 이 공간을 마련하였습니다.

운영체제와 하드웨어 사이의 상호작용을 깊이 있게 이해하고, 시스템 전체의 흐름을 조망할 수 있는 엔지니어링 시각을 기르는 것을 목표로 합니다.  
커널 내부의 복잡한 메커니즘을 이해하고 분석하는 과정과, eBPF를 활용해 시스템을 효율적으로 관찰하고 진단하는 기술들을 주로 다루고자 합니다.
